Cloudflare R2 (非公式MODアップロード用)

1 バケット作成
2 パブリックURL
3 CORS設定
4 APIトークン

1. Cloudflare ダッシュボードにログインし、「R2」を開きます。 Cloudflare ダッシュボード

2. 「バケットの作成」 から好きな名前 (例: my-mod-repo) で作成します。これが Bucket Name になります。

3. 作成したバケットの設定から R2.dev サブドメイン を「許可」にします。

※ 注意: これを許可すると、URLを知っている全員がMODをダウンロード可能になります。プライベートなファイルは置かないでください。

表示されたパブリックURL (https://pub-xxxx.r2.dev 等) が Public URL になります。

4. (重要) 設定画面の CORS ポリシー で「CORS ポリシーの追加」から以下を設定してください。これがないと他の人がダウンロードできません。

  • ・許可されるオリジン: * または tauri://localhost
  • ・許可されるメソッド: GET

5. R2トップページ右上の R2 API トークンの管理 から「API トークンの作成」をします。

6. 「オブジェクト 読み取りと書き込み」権限で作成します。
表示された アクセスキー ID を アクセスキー の欄にコピーしてください。

7. 同様に シークレットアクセスキー をコピーして一番上の欄に貼り付けます。

ModLinker へようこそ！

ModLinkerは、お友達やサーバーのメンバーと一緒に、MinecraftのMOD構成をかんたんに揃えるためのツールです。

「マニフェストファイル (JSON)」という設計図をやり取りするだけで、みんなと同じMOD環境をすぐに作ることができます！

他の人の環境を取り込む（ダウンロード）

配られたマニフェストファイルを使って、必要なMODを一気にダウンロードします。

  • 📂 ファイルを選ぶだけ：複雑な操作は不要です。
  • ⚡ 差分だけをダウンロード：すでに入っているMODはスキップするのでとても速いです。
💡 ヒント： 「ダウンロード」タブからJSONファイルを選び、「差分をチェック」を押すだけでOKです！

自分の環境を配る（マニフェスト生成）

今のあなたの「mods」フォルダの中身をリストアップし、みんなに配るための設計図を作ります。

  • 🌐 公式MODは自動リンク：Modrinth などの配布元を自動で特定します。
  • ☁️ 非公式MODはクラウドへ：自作MODなどは Cloudflare R2 に自動でアップロードして共有できます。
