マニフェストを渡すだけ。フレンドとのマルチプレイ準備が、これまでにないほど簡単に。

## 🌟 ModLinkerとは？

Minecraftでマルチプレイをする際、「参加者全員に同じMODを導入してもらう」のは非常に面倒です。
ModLinkerは、この課題を解決するための次世代MOD同期ツールです。
「配る側」はワンクリックで設計図（マニフェスト）を作成し、「受け取る側」はそれを読み込むだけで足りないMODだけを超高速で自動ダウンロードします。

## ✨ 主な機能

### 1. 超高速な差分同期 (受け取る側)
配られた `modlinker-manifest.json` を読み込むだけで、必要なMODを一気にダウンロードします。すでに導入済みのMODは自動でスキップする「差分ダウンロード」なので、無駄な待ち時間はゼロです。

### 2. マニフェスト自動生成 (配る側)
自分の `mods` フォルダをスキャンするだけで、配布用の設計図（JSON）を作成します。
Modrinth などの公式MODは自動でダウンロードリンクを取得します。

### 3. 自作MODも自動クラウド共有
公式にない自作MODやリソースパックなどの非公式ファイルは、自動で Cloudflare R2（クラウドストレージ）にアップロードし、誰でもダウンロードできるように自動でリンクを生成します。配布の手間を極限までカットします。

### 4. 美しいモダンUI
Glassmorphism（すりガラス風）を採用した直感的で洗練されたデザイン。
多言語対応（日本語、英語、中国語など10ヶ国語以上）やダークモードにも完全対応しています。

## 🚀 使い方

### ホスト（MOD環境を配る人）
1. ModLinkerを起動し、左側のメニューから **マニフェスト生成** を開きます。
2. 「スキャン開始」をクリックします。
3. 自動で `mods` フォルダが解析され、`modlinker-manifest.json` が生成されます。
4. このJSONファイルをDiscord等でフレンドに渡します。

### ゲスト（MOD環境を受け取る人）
1. ModLinkerを起動し、**ダウンロード** モードを開きます。
2. ホストからもらった `modlinker-manifest.json` を選択します。
3. 「差分をチェック」をクリックします。
4. あとは足りないMODが自動でダウンロードされるのを待つだけ！

## 🛠️ インストールとビルド

### ダウンロード
[GitHub Releases](https://github.com/userkunngakkou/modlinker/releases) からお使いのOSの実行ファイルをダウンロードしてください。インストール不要のポータブル版としてそのまま使用できます。

### 開発環境のセットアップ

Node.js (v20以上) と Rust の環境が必要です。

\`\`\`bash
# 依存関係のインストール
npm install

# 開発用サーバーの起動
npm run tauri dev

# リリースビルドの作成
npm run tauri build
\`\`\`

## 📝 必要な設定 (R2 クラウド連携)
非公式MODをクラウドに自動アップロードする機能を使用するには、初回のみ Cloudflare R2 の API 設定が必要です。
アプリ内の「設定」画面から、以下の項目を入力してください。
- バケット名
- R2 公開用URL
- S3 エンドポイント
- アクセスキーID
- シークレットアクセスキー

設定方法の詳細は、アプリ内の「説明書」ボタンから画像付きのガイドをご確認いただけます。
