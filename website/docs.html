ModLinker へようこそ

ModLinkerは、お友達やサーバーのメンバーと一緒に、MinecraftのMOD構成をかんたんに揃えるためのツールです。

「マニフェストファイル (JSON)」という設計図をやり取りするだけで、みんなと同じMOD環境をすぐに作ることができます！

ZIPファイルでの配布とは違い、ModrinthやCurseForgeから直接ダウンロードするため著作権的にクリーンであり、配布の手間も大幅に削減されます。

他の人の環境を取り込む（ダウンロード）

サーバーの管理者やお友達から配られたマニフェストファイルを使って、必要なMODを一気にダウンロードします。

手順

  1. アプリの左メニューから「ダウンロード」を選択します。
  2. 「ゲームディレクトリ」に、Minecraftのフォルダ（例: .minecraft）を設定します。
  3. 「マニフェストファイル」に、受け取った manifest.json を指定します。
  4. 「差分をチェック」ボタンを押します。
  5. まだインストールされていないMODのリストが表示されるので、「ダウンロード開始」を押します。

※すでに入っているMODはスキップするため、2回目以降の同期は一瞬で終わります。

自分の環境を共有する（マニフェスト生成）

あなたの環境にあるMODリストから、共有用の設計図（JSONファイル）を作成します。

手順

  1. アプリの左メニューから「マニフェスト生成」を選択します。
  2. 「ゲームディレクトリ」に、あなたのMinecraftのフォルダ（mods/ などが入っている場所）を設定します。
  3. 「マニフェスト生成を開始」ボタンを押します。
  4. アプリが自動的にローカルのMODをModrinthやCurseForgeと照合し、リストアップします。
  5. 「保存」ボタンを押して manifest.json を書き出し、お友達に共有してください。

公式に存在しない野良MODなどがある場合は、Cloudflare R2を利用することで自動的にクラウドへアップロードし、ダウンロードURLを付与することが可能です。詳しくは次のセクションをご覧ください。

Cloudflare R2 の設定 (野良MODの配布)

ModrinthにもCurseForgeにも無い独自のMODを配る場合、Cloudflare R2（毎月10GBまで無料）を利用して自動配布が可能です。

1. バケットの作成

Cloudflareダッシュボードにログインし、「R2」からバケットを作成します。

2. バケットの公開アクセス許可 (CORS設定)

アプリがクラウドからMODをダウンロードできるように、CORSポリシーを設定します。

バケットの「設定」タブから「CORS ポリシー」を編集し、以下のJSONを貼り付けます。

json 
[
  {
    "AllowedOrigins": [
      "*"
    ],
    "AllowedMethods": [
      "GET"
    ],
    "AllowedHeaders": [
      "*"
    ],
    "ExposeHeaders": []
  }
]

3. APIトークンの作成

「R2 API トークンの管理」から新しいトークンを発行します。権限は「オブジェクト読み取りと書き込み」にしてください。

4. ModLinker への設定

ModLinkerの「設定」タブを開き、以下の情報を入力します。

  • Account ID: Cloudflareダッシュボード右下に表示されるID
  • Bucket Name: 先ほど作成したバケット名
  • Access Key ID: トークン作成時に表示されるアクセスキー
  • Secret Access Key: トークン作成時に表示されるシークレットキー
  • Public URL: バケットのカスタムドメイン、または r2.dev の公開URL
text 
https://pub-xxxxxxxxxxxxxxxx.r2.dev

これらを設定して保存すると、次回マニフェストを生成する際、見つからなかったMODが自動的にあなたのバケットへアップロードされます！
